Project Summary
You are building FreshBox, a console-based meal kit ordering system for a fictional meal kit delivery company. 

FreshBox offers various types of meal kits — vegetarian options, family-sized portions, and premium gourmet selections — each with different pricing, serving sizes, and special features.

The company needs a system where:

Customers can browse the catalog of available meal kits
Orders can be created with multiple items and scheduled delivery dates
Inventory is tracked to prevent over-ordering
Validation ensures orders meet business rules (minimum lead time, valid quantities)
Building FreshBox provides hands-on experience with the architectural patterns found in real enterprise Java applications. The layered structure - moving from domain to services to handlers - mirrors production systems, while the use of custom exceptions with rich data fields reflects how professional applications handle errors.

Mastering these patterns equips you with the fundamental skills required to build REST APIs, microservices, and robust backend systems throughout your Java career. These are the core competencies you will rely on as you advance.

Estimated completion time: 4-6 hours
